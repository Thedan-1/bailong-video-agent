# 案例 01｜《双城之战》32 秒群像卡点

**先理解素材和音乐，再用时间线组织人物、叠框与声音。**

这是「爱剪视频的白龙娘」的一次 AI 辅助混剪实践。这里公开制作思路与整理后的提示词；相关工具代码后续按模块整理。

## 可复用提示词

以下根据制作记录整理，**不是逐字原始提示词**。具体人物、音乐和时长可替换。

> 使用我提供且可用于本次制作的视频、音乐和角色原声，制作约 32 秒的群像卡点短片。先分析素材、参考片段的构图变化和音乐起音，整理人物镜头与卡点时间线。
>
> 重音展示人物，连续音符推动不同大小、横竖比例的视频框逐层叠入；框内动作继续播放，段尾用强动作收束。构图要有变化，不要全用扇形排布，前后半段不要重复镜头。英文人物名字分别设计，避免所有人物套同一种效果。
>
> 每人使用自然语速的完整英文短句，在下一人物转场前结束；保留合适的打击与呐喊原声，并让音乐适度退让。结尾在原时长内淡出。先输出关键段预览，检查后再导出全片，核对人物、对白、时长和编码。

## 六步制作流程

1. **整理素材与镜头。** 为本地剧集生成选片图，记录角色、动作和时间码；观察参考片段的视频框比例、遮挡层次与进出顺序，形成镜头清单。
2. **分析音乐起音。** 比较原速与 95% 速度，使用短时傅里叶变换，计算 2–8kHz 频段的正向谱通量，生成瞬态起音候选，再选定剪辑落点。这是起音线索，不是电吉他分轨或逐音转谱。
3. **编排人物段落。** 多数人物段约两秒：重音出场、连续起音叠框、段尾动作收束。把素材入出点、画框出现时间与人物文字写进时间线。
4. **合成画面。** 使用 Python 与 OpenCV 逐帧处理视频框、透视、蒙版、文字和边缘碎片；横竖框交错、大小与层次变化，框内动作保持连续。
5. **整理对白与混音。** 采用完整英文短句，保持自然语速，不内部拼句；结合均衡、压缩、音量包络和中频退让，协调对白、打击、施法喊声与 BGM。
6. **导出与检查。** 从原分辨率素材取段，文字图形按两倍尺寸渲染，分段编码后统一时间基准；核对帧数、时长、抽帧构图、全片解码及音频衔接。

## 工具与输入

实际使用：**Python、NumPy、SciPy、OpenCV、Pillow、Matplotlib、FFmpeg / ffprobe**；最终视频采用 NVENC 编码。

输入包括：视频素材、BGM、角色原声、可用字体、素材时间段及创作要求。中间产物包括：镜头清单、起音候选、时间线、混音记录与导出验收结果。

原片为 3840×1632、约 24fps；60fps 指合成输出帧率。本案例未使用 AI 超分或运动插帧，部分近景经过裁切与重采样。BGM 采用采样调速，音高随速度变化。
