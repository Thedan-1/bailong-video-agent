# 工具目录草案

以下是工具职责划分，不是当前可调用 API。预留文件只包含说明，核心实现将分批整理。

## 热点与素材

| 工具方向 | 输入 | 输出设想 |
| --- | --- | --- |
| 热点聚合 | 主题、时间窗、允许的数据来源 | 含来源与时间的候选选题 |
| 讨论分析 | 公开讨论与关联上下文 | 观点分组、变化线索与摘要 |
| 素材检索 | 主题、角色、来源范围 | 候选素材与出处 |
| 素材归档 | 用户文件或获准使用的素材 | 元数据、去重索引与素材清单 |
| 镜头理解 | 素材、时间区间 | 镜头边界、角色、动作、语义索引 |
| 参考分析 | 参考片段 | 镜头长度、音乐落点、结构与转场笔记 |

## 卡点与音乐

| 预留文件 | 任务 | 结果边界 |
| --- | --- | --- |
| `structure.py` | 分析 BGM 段落、变化与能量走向 | 段落边界为分析结果，可修订 |
| `beats.py` | 节拍、速度和重拍候选 | 有速度变化、切分节奏时需检查 |
| `kick.py` | 底鼓落点候选 | 低频能量峰不直接等于底鼓 |
| `instruments.py` | 电吉他等乐器的出现线索 | 保留置信度，不保证逐件识别 |
| `frequency.py` | 高、中、低频能量与瞬态变化 | 频段分析不等于音轨分离 |
| `separation.py` | 为后续分析提供分离声部 | 独立可选工具，质量与依赖随模块说明 |

剪辑规划综合段落、节拍、动作和用户要求，不默认每一拍都切镜头。

## 故事与时间线

| 预留文件 | 任务 | 输出设想 |
| --- | --- | --- |
| `story.py` | 事件顺序、叙事段落与旁白布局 | 可检查的故事剪辑计划 |
| `beat.py` | 音乐段落与镜头落点匹配 | 带素材时间码的卡点计划 |
| `timeline.py` | 组织视频、音频、字幕与转场 | 统一时间线描述 |
| `adapters.py` | 对接具体剪辑工程或渲染器 | 由相应适配器定义的输出 |
| `checks.py` | 检查缺失素材、时长与输出参数 | 检查报告 |

外部检索、模型、音源分离及渲染后端均通过适配器接入；不在骨架中绑定某个付费服务。
