# 流程配置草案

这些 YAML 用来说明模块如何组合，当前不由任何已发布执行器读取，字段也不是稳定 API。

| 配置 | 使用场景 | 可跳过的阶段 |
| --- | --- | --- |
| `local-beat.yaml` | 用户给定素材与 BGM，走卡点路线 | 热点发现、在线素材检索 |
| `local-story.yaml` | 用户给定素材和主题，走故事路线 | 热点发现、在线素材检索 |
| `trend-to-video.yaml` | 从热点候选开始，检索后创作 | 可将热点阶段关闭并提供主题 |

参考视频用于分析剪辑风格，不默认作为可直接使用的片源。示例路径为占位路径，需要由实际项目替换。
